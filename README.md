# 拾页 — 个人博客与管理后台

一个无需构建工具的中文博客 demo，包含访客页面和可交互的管理后台。

## 直接预览

打开 `index.html` 即可浏览博客。点击右上角“进入管理后台”登录演示后台：

- 用户名：`admin`
- 密码：`admin123`

## 功能

- 访客端文章列表、分类筛选、搜索和文章阅读页
- 管理端概览、文章新建/编辑/删除、发布/草稿切换
- 后台用户的新增、编辑、删除和角色管理
- 博客名称、标语、简介与联系邮箱设置
- 数据保存在当前浏览器，可在设置页恢复初始演示数据
- 适配手机和桌面屏幕

## 数据和部署说明

这是一个 GitHub Pages 可托管的静态演示站点。登录账号和数据仅在浏览器中模拟，不提供真实身份验证、跨设备同步或服务器数据库；请勿在此 demo 中存放真实用户资料。需要正式运营时，应连接具备身份验证和数据库的后端服务。
